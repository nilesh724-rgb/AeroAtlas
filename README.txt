AEROATLAS — AVIATION EXPLORER

WHAT'S INCLUDED
- Responsive one-page aviation website
- Interactive route estimator with 59 international airports, including Mauritius (MRU)
- Interactive Leaflet flight map with satellite imagery and street-map toggle
- Great-circle route arc, departure/arrival markers and route zoom-to-fit
- Six one-click popular route presets
- Great-circle distance calculation (Haversine formula)
- Aircraft-specific flight-time estimates and indicative range check
- Searchable/filterable fleet of 17 aircraft across seven manufacturers
- Aircraft detail popups with specifications and facts
- Mobile navigation and responsive layouts

HOW TO OPEN
1. Extract the ZIP file (if you downloaded the ZIP).
2. Open index.html in Chrome, Edge, Firefox or Safari.
3. An internet connection is needed for Leaflet, satellite/street map tiles, hosted aircraft photographs and Google Fonts.

HOW TO PUBLISH WITH GITHUB PAGES
1. Create a new GitHub repository, or use a repository you control.
2. Upload index.html, styles.css, app.js and this README, keeping the same file structure.
3. In the repository, open Settings > Pages.
4. Under Build and deployment, choose Deploy from a branch, select main and / (root), then Save.
5. GitHub Pages will provide the public website URL after deployment.

FLIGHT ESTIMATE NOTES
Distances are great-circle distances between the airport coordinates in the data file. Estimated time applies a simple 6% distance allowance, 91% of the listed cruise speed as an average-speed approximation, and 29 minutes for climb/descent/ground allowance. It is a learning/entertainment estimate, not an operational flight-planning, dispatch, fuel, or safety tool. Real flight duration varies with routing, winds, aircraft weight, weather, air traffic and airline procedures. Aircraft range and seating figures are indicative and vary by variant, operator and configuration.

PHOTOGRAPHY
The aircraft photographs are remotely loaded from their respective image hosts so the package stays lightweight. The prototype uses image assets from The Independent, Lufthansa Group, Aviation Week, Unsplash and other aviation/photo publishers. Check each publisher's current image terms and obtain permission or replace images with your own/licensed photographs before public or commercial use. Text alternatives are included in the image markup.

CUSTOMISATION
- Airport coordinates and aircraft specifications are near the top of app.js.
- Aircraft photographs, names, range, cruise speed and facts are stored in the aircraft array in app.js.
- Design colours and responsive styling are in styles.css.
